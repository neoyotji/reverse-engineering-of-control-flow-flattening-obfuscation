# Reverse Engineering of Control Flow Flattening Obfuscation
Control Flow Flattening (CFF) is a widely used software obfuscation technique that reorganizes a program's nested block structure around a single central dispatcher and state variable, hindering both static and dynamic analysis. This thesis proposes a five-stage methodology for reverse engineering CFF-protected Windows PE (x86/x64) binaries, combining static pre-processing with dynamic/symbolic execution. The relevant literature was first surveyed systematically, from the origins of the technique to recent deobfuscation approaches, identifying key open gaps; an analysis pipeline built on IDA Pro/Ghidra, Triton, and angr was then designed. To test the method's core assumption, a real pilot experiment was conducted on a manually CFF-transformed test program: angr's static CFG analysis successfully identified the dispatcher structure via a graph-theoretic metric (in-degree concentration), and subsequent symbolic execution fully recovered the dispatcher's hidden decision logic at the behavioral level (4/4 branches) without access to source code. The findings demonstrate that the proposed approach works at single-sample scale, but remain at a proof-of-concept stage pending full state-level transition table extraction, taint-analysis integration, large-scale dataset evaluation, and comparison with existing tools. Concrete recommendations for the remaining thesis work are provided accordingly.
